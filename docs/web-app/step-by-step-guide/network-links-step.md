# Network links step

In this step, you define the network link candidates that let energy flow
between the hubs of your scenario, for example a district heating pipe or an
electrical connection. For background, see the
[Network technologies](../concepts/network-technologies.md) and
[Intra-hub networks](../concepts/intra-hub-networks.md) concept pages.
