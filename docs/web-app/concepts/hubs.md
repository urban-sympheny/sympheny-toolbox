# Hubs

![Hubs step in the scenario editor](img/hubs-1.png)

Sympheny lets you define different geographic areas or sites within your scenario as hubs. Every hub has an energy system with an energy balance. The energy demands in the hub need to be satisfied using available imports, on-site resources, conversion technologies, and storage technologies.

A hub can be an individual building or a group of buildings treated as a single energy system. A hub can cover a large area, like an entire region or country.

Multiple hubs can be connected together using network links and network technologies to model how energy flows between them. A hub can also be a node, connecting multiple network links together, without any energy conversion or storage technologies.

For parameters, see [Hubs parameters](../parameters/hubs.md).
