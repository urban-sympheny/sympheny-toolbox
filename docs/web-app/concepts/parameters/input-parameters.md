# Input parameters

Sympheny lets you consolidate all your input data into a single Excel file. This file is organized into separate worksheets, with each worksheet representing a specific component of your scenario model:

- [General parameters](general.md)
- [Stages parameters](stages.md)
- [Hubs parameters](hubs.md)
- [Energy carriers parameters](energy-carriers.md)
- [Conversion technology parameters](conversion-technologies.md)
- [Energy demands parameters](energy-demands.md)

!!! note
    Any parameter without a default value is required.
