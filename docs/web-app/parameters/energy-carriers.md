# Energy carriers

| Parameter | Definition | Unit | Default |
| --- | --- | --- | --- |
| Energy Carrier Name | The name of the energy carrier; each name must be unique. | n/a | n/a |
| Energy Carrier Type | The type of the energy carrier. Only used to determine the default color. | n/a | n/a |
| Energy Carrier Subtype | The sub type of the energy carrier. Only used to determine the default color. | n/a | n/a |
| Energy Carrier Color | The HEX color code of the energy carrier. Only used for the energy hub diagram and results dashboard. | n/a | n/a |
