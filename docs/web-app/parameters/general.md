# General

| Parameter | Definition | Unit | Default |
| --- | --- | --- | --- |
| Currency | The currency specified is used to interpret the cost parameters in the input file. It does not influence the model itself; it is solely for parsing the input file and ensuring accurate representation of cost units in the web app and results. | n/a | CHF |
| Exchange Rate | The exchange rate from CHF is applied to all economic data in the technology databases. | n/a | 1 |
